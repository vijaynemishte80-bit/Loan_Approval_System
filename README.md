# Loan_Approval_System


📌 Project Overview

This project predicts whether a loan application will be approved or not using machine learning models. It analyzes applicant details like income, credit score, employment status, and other financial indicators to make accurate predictions.

---

🎯 Objective

- Build a classification system for loan approval prediction
- Compare multiple machine learning models
- Select the best model based on performance metrics

---

🧠 Models Used (in order)

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Naive Bayes

---

⚙️ Project Workflow

1. Data Preprocessing

- Handling missing values
- Encoding categorical variables
- Feature Engineering

2. Exploratory Data Analysis (EDA)

- Data visualization using graphs
- Understanding feature relationships

3. Feature Scaling

- Standardization applied to numerical features

4. Model Training

Models were trained in the following sequence:

- Logistic Regression
- KNN
- Naive Bayes

---

📊 Model Evaluation

All models were evaluated using the following performance metrics:

- Accuracy Score
- Precision Score
- Recall Score
- F1 Score

Each model's performance was compared to determine the most effective one for loan approval prediction.

---

🏆 Best Model Selection

The best model was selected based on overall performance across all evaluation metrics (accuracy, precision, recall, and F1 score). The selected model provides the most reliable predictions for loan approval.
